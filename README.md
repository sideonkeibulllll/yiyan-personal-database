## 它到底是个什么东西

市面上大多数笔记工具，都在逼你做同一件事：在「存进去」的那一秒就决定
它该进哪个文件夹、打什么标签、以后要怎么找得到它。

可真正值得留下的东西，从来都是在你没准备好的时候冒出来的——
半句话、一个念头、一段删了心疼、留着又没再看的聊天记录。

所以记忆库是反着来的。

> **存的时候不用想分类，抽的时候它会自己找上你。**

想不起来该放哪，就别想。你只管往里扔，
它负责在你快要忘了的时候，把该出现的那条重新推到你面前。

它不是效率工具，不追求一切都井井有条。
它更像一个会遗忘、也会突然想起来的抽屉。你今天撞见的那条三个月前的笔记，
说不定正好是今天要的答案。

### 一眼全景

它由 **六个小工具**，加 **一层会主动找你的壳** 组成：

| 模块 | 一句话 |
|---|---|
| **首页 · 收集** | 一个输入框，粘进去就完事。不问标题，也不给第二次机会 |
| **随机页 · 重逢** | 一屏卡片翻出来，你舍不得的那些更容易再撞上你 |
| **待办** | 极简待办：下滑添加，左滑删除，右滑完成 |
| **备忘录** | Markdown 长文，本地存图，写点长的 |
| **AI 对话** | 会真的动手帮你整理，不只会陪你聊天 |
| **组织** | 标签、分组、连线、决定转盘 |
| **桌面组件** | 六种形态摆在桌面，不用点开 App 也能被自己说过的话撞一下 |
| **记忆来信** | 每天在一个说不准的时刻，一张卡自己送进通知栏 |

前六个是工具，后面那两个是「壳」——让这个抽屉不再只是干等着你打开。

### 它的三条脾气

**一、本地优先，没有账号这回事。**
数据躺在你手机里的 SQLite。装完直接用，没有注册，没有登录，没有用户系统。
断网能用，所有核心功能离线可用。

**二、偏心是故意的。**
随机不是公平的：你标过星的、最近用过的，更容易被抽到。
好东西不该沉底——这是这套算法唯一的偏爱。

**三、它不只会等你。**
桌面上的橱窗、通知栏里的来信、小组件里的转盘。
它会用很轻的方式主动出现，但不打扰你正在做的事。

## 功能详情

### 首页 · 收集（存，不用想）

- **一个输入框**：粘贴、选图、发送，就这一下——不问你标题叫什么
- **图片附件**：相册选图或者直接拍照，跟着卡片一起存本地
- **智能标签**：懒得打标签？让 AI 读一遍，给你几个建议
- **草稿保护**：输入框内容每 5 秒存一次快照，App 被系统杀掉也不丢
- 每条内容都是一张独立卡片

### 随机页 · 加权抽卡

每次给你一屏卡片，但不是一视同仁的公平：

| 卡片状态 | 被抽中的权重 |
|---------|------------|
| 普通卡片 | 1 倍 |
| 星标过的 | +1 倍 |
| 近 5 天内复制或编辑过的 | +1 倍 |
| 星标 + 近期，两者都有 | **3 倍** |

换句话说，**你标记过的、最近用过的东西，会更容易再次出现在你眼前。**
好内容不该沉底，这是这个算法唯一的偏心。

- 可以按标签 / 时间 / 星标限定抽取范围，筛选条件会被记住
- 「刷新下一屏」由你说了算，不会自己乱跳
- **卡片右箭头 → 卡片浏览页**：只读地、干干净净看完整一张卡，正文全文、大图、标签、来源、时间一页看完
- 从通知点进来的卡会置顶并高亮一下，然后安静等你

### 记忆来信 —— 它学会自己敲门了

以前它只能等你想起它。打开「设置 → 记忆来信」之后：

| 设计 | 说明 |
|------|------|
| **随机邂逅** | 不做固定闹钟——每天在你设的时间窗口内（默认 10~22 点）随机挑一个时刻 |
| **它只说一句** | 标题是「X 天前的记忆来信」，正文就是卡片原文 |
| **点开就走** | 点通知直达那张卡的浏览页，不是任务列表，也不是一堆未读 |
| **同一套偏心** | 选卡复用随机页的加权算法，并自动避开最近通知过的卡 |
| **有分寸** | 每天最多 1~3 条（默认 1）；**开关默认关闭**，关掉就清空排程 |
| **开机不丢** | 预排未来 7 天，每次打开 App 自动补缺续排 |

- 通知渠道「记忆来信」是独立的，系统设置里可以单独调它的打扰级别
- 「立即试一发」按钮：3 秒后掉一张卡，先验货再决定要不要长期开着
- 部分国产手机（小米 / 华为 / OV）需要在系统设置里允许「自启动 / 后台运行」，
  否则通知可能被系统拦掉

### 待办 —— 不只是清单

- **日期文件夹**：一天一个文件夹，时间线清楚
- **三视图 + 手势**：下滑添加，左滑删除，右滑完成
- **标签**：给待办打彩色标签，双击删、长按改名
- **模板**：重复的事一次配好，下次一键铺开
- **图片附件**：给待办配上截图说明
- **回收站**：删错了能捞回来
- **拖拽排序 / 长按菜单**：手机上顺手
- 首页会把你**今天该做的事**挑出来提醒你

### 备忘录 —— Markdown 长文

- 原生 Markdown 写作：标题、粗体、列表、引用、表格、行内代码
- **本地图片**：直接插入，图片存在本地，不占云空间
- **表格内嵌横向滑动**：长表格不会把屏幕撑破
- **光标进图片行时，源码与图片同显**：不会闪，不会抖（照着 Obsidian 的手感做的）
- 底栏有撤销 / 恢复按钮，手机上也能 Ctrl+Z
- 支持多篇文档、大纲导航、上次位置自动跳回

### AI 对话 —— 会动手的助手

接 **DeepSeek / 硅基流动 / 智谱 GLM（自带免费池）**，多模型一键切换，
支持深度思考与流式输出。

**它不只是聊天，它真的能帮你整理**——一共 **31 个工具**，分四组：

| 分组 | 数量 | 能力 |
|------|------|------|
| 数据卡片 | 11 | 搜索、创建、编辑、打标签、分组、星标、连线、删除 |
| 待办事项 | 10 | 查今天、搜索、创建、编辑、完成、删除、标签管理 |
| 备忘录 | 6 | 搜索、读取、新建、追加、覆写、删除 |
| 长期记忆 | 4 | 记住 / 查看 / 修改 / 删除关于你的事实（跟随开关自动启用） |

前三组在输入框的 MCP 面板里独立勾选；长期记忆那组由设置里的开关控制。

几个让人放心的设计：

- **批量操作**：一句话就能同时处理多条，不用一条条来
- **先查再建**：它会先看现有的标签和分组，不会越用越碎
- **删除必须你点确认**：删东西时对话里会弹出「确认 / 取消」，
  **AI 会停在那儿等你点**，你点了它才动手
- **长期记忆**：你告诉过它的重要事实会被单独存起来（上限 100 条），下次对话还记得

### 桌面组件 —— 六种形态

长按桌面空白处 → 小组件 → 找到「记忆库」，可以摆上：

| 组件 | 它干什么 |
|------|---------|
| **记忆卡片** | 桌面上开一扇小橱窗，展示一张你的卡，点它直接跳到那张卡 |
| **记忆卡片 · 换一张** | 同上，多一个「换一张」按钮——在今天排好的 10 条候选里循环翻 |
| **待办清单** | 今天的待办直接摊在桌面，可以勾选完成 |
| **niko 挂件** | 挂在绳上的吉祥物。会静看，会摆动，能吸墙；戳一下它会挨一记暴击，然后犯晕 |
| **决定转盘** | 选择困难的裁判：把盘面搬到桌面，跳字定格 |
| **时钟** | 极简 HH : mm，靠系统自己走字，不需要 App 常驻 |

六种组件**各自独立**配置背景样式：

| 档位 | 效果 | 适合 |
|------|------|------|
| `default` | 不透明深棕底 | 字迹最稳，浅色 / 杂色壁纸首选 |
| `blend` | 透亮融合（约 69% 半透明） | 想让壁纸透出来，又不想太突兀 |
| `ultra` | 极致透明（约 10% 薄纱） | 最大程度露出壁纸，靠文字投影保证可读 |

- 真·背景虚化（毛玻璃）在 AppWidget 上做不到——小组件由 launcher 进程绘制，
  没法采样它背后的内容。所以上面是「半透明融合」的视觉近似，不是实时模糊。
- **niko 底层时钟**：可以在 niko 背后叠一个放大的数字时钟，跟背景样式不冲突，随意组合。

### 组织起来

- **标签**：手动加，或者让 AI 建议；支持合并、重命名
- **分组**：更大颗粒的收纳
- **连线**：把两张卡连起来，还能顺着线索多级探索——
  「为什么这两条会有关联」这件事本身也值得记下来
- **决定转盘**：配好几套预设盘面，还存着最近的转动记录
- **导出**：随时把数据导出来（JSON / Markdown），不会被锁在这个应用里

### 备份（可选）

默认不联网。想要多设备同步或者换机迁移，可以自己配云备份
（Cloudflare D1 存文本 + R2 存附件，走你自己部署的中转站）——
**开不开、用什么，都是你说了算**。

- **增量备份**：只传上次备份之后动过的部分
- **恢复合并**：按内容 hash 去重，不会把已有的东西再复制一份
- 数据管理器里可以直观地查看、清理条目

## 关于隐私

这不是一句口号，是这个应用的结构本身：

- **数据默认只存在你的手机里**（本地 SQLite 数据库）
- **不需要注册账号**，没有用户系统，我们也没有你的任何数据
- **不联网也能用**：全部核心功能离线可用
- **AI 功能要你自己填 API Key**，请求直接发给你选的模型服务商，中间没有我们的服务器
- **安装包里不含任何云服务密钥**（需要的话，密钥只存在你自己的设备设置里）
- **零埋点**：没有统计，没有广告 SDK，也没有「升级到专业版」这种弹窗

## 常见问题

**Q：装的时候提示「未知来源」，有风险吗？**
A：这是 Android 对所有非应用商店安装包的统一提示。官网给了 SHA-256，下载完可以自己比对。

**Q：我的数据会被上传吗？**
A：不会。除非你自己在设置里开了云备份，否则它不会主动上传任何东西。

**Q：不填 API Key 能用吗？**
A：能。录入、随机、待办、备忘录、搜索、转盘、桌面组件这些跟 AI 一点关系都没有，
全都照常用。AI 只是锦上添花，而且 GLM 还有个免费池可以白嫖。

**Q：换手机怎么迁移？**
A：用「数据导出」导出 JSON / Markdown，或者配好云备份后在新机上恢复。

**Q：为什么有些地方长得像 Obsidian？**
A：因为作者自己用 Obsidian，觉得「源码和渲染共存」的手感最好，就照着做了。

**Q：下载到的版本跟这里写的版本号不一样？**
A：官网下载页可能比源码主线滞后一两个版本，以页面上标的为准。
想追最新的话，直接看仓库的 commit 和 tag。

**Q：有 iOS 版吗？**
A：没有，也不打算有。

**Q：为什么我的国产手机收不到记忆来信？**
A：小米 / 华为 / OV 这类系统默认会拦后台通知，需要在系统设置里允许「自启动 / 后台运行」。
