它不追求「效率工具」那种一切都井井有条的样子。

你今天抽到的那条三个月前的笔记，可能正好是今天需要的答案。

## ✨ 它能做什么

### ✍️ 收集 —— 存，不用想

- **极速录入**：一句话、一段链接、一个念头，粘进去就完事
- **来源 / 补充**：想记出处就记，不记也不拦你
- **智能标签**：懒得打标签？让 AI 读一遍给你建议
- **自动保存为卡片**：每条内容都是一张独立卡片

### 🎲 重新遇见 —— 加权抽卡

随机页每次给你一屏卡片，但不是一视同仁的公平：

| 卡片状态 | 被抽中的权重 |
|---------|------------|
| 普通卡片 | 1 倍 |
| ⭐ 星标过的 | +1 倍 |
| 🕐 近 5 天内复制或编辑过的 | +1 倍 |
| ⭐ + 🕐 两者都有 | **3 倍** |

也就是说，**你标记过的、最近用过的内容，会更容易再次出现在你眼前。**
好内容不该沉底，这是这个算法唯一的偏心。

- 可按标签 / 星标筛选，筛选条件会被记住
- 「刷新下一屏」由你说了算，不会自己乱跳

### 📋 待办 —— 不只是清单

- **日期文件夹**：每一天一个文件夹，时间线清楚
- **模板**：重复的事一次配好，下次一键铺开
- **图片附件**：给待办配上截图说明
- **回收站**：删错了能捞回来
- **拖拽排序 / 长按菜单**：手机上顺手
- 首页会把你**今天该做的事**挑出来提醒你

### 📝 备忘录 —— Markdown 备忘录

- 原生 Markdown 写作：标题、粗体、列表、引用、表格、行内代码
- **本地图片**：直接插入，图片存在本地数据库，不占用云空间
- **表格内嵌横向滑动**：长表格不会把屏幕撑破
- **光标进图片行时，源码与图片同显**：不会闪、不会抖（对齐 Obsidian 的手感）
- 底栏有撤销 / 恢复按钮，手机上也能 Ctrl+Z
- 支持多篇文档、大纲导航、上次位置自动跳回

### 🤖 AI 对话 —— 会动手的助手

接 DeepSeek / 硅基流动 / 智谱 GLM（自带免费池），多模型一键切换，支持深度思考与流式输出。

**它不只是聊天，它真的能帮你整理** —— 共 **23 个工具**，分三组按需开启：

| 分组 | 能力 |
|------|------|
| 📊 数据卡片 | 搜索、创建、编辑、打标签、分组、星标、连线、删除 |
| ✅ 待办事项 | 查今天、搜索、创建、编辑、完成、删除 |
| 📝 备忘录 | 搜索、读取、新建、追加、覆写、删除 |

几个让人放心的设计：

- **批量操作**：一句话就能同时处理多条，不用一条条来
- **先查再建**：AI 会先看现有的标签和分组，不会越用越碎
- **删除必须你点确认**：删东西时对话里会弹出「确认 / 取消」，
  **AI 会停在那里等你点**，你点了它才动手
- **对话级记忆**：工具开关跟着本次对话走，退出再进来还是原样

### 🔗 组织起来

- **标签**：手动加、AI 建议；支持合并、重命名
- **分组**：更大颗粒的收纳
- **连线**：把两个卡片连起来，还能顺着线索多级探索 ——
  「为什么这两条会有关联？」这件事本身也值得记下来
- **转盘**：配置多个选项转盘，做选择困难时的裁判
- **导出**：随时把数据导出来，不会被锁在这个应用里

### ☁️ 备份（可选）

默认不联网。想要多设备同步或换机迁移，可以自己配置云备份，
数据同步到你指定的存储里 —— **开不开、用什么，都是你说了算**。

## 🔒 关于隐私

这不是一句口号，是这个应用的架构：

- **数据默认只存在你的手机里**（本地 SQLite 数据库）
- **不需要注册账号**，没有用户系统，我们也没有你的任何数据
- **不联网也能用**：全部核心功能离线可用
- **AI 功能要你自己填 API Key**，请求直接发给你选择的模型服务商，
  中间没有我们的服务器
- **安装包里不含任何云服务密钥**（密钥若需要，只存在你自己的设备设置里）

## ❓ 常见问题

**Q：装的时候提示「未知来源」有风险吗？**
A：这是 Android 对所有非应用商店安装包的统一提示。官网提供 SHA-256 校验值，下载后可自行比对。

**Q：我的数据会被上传吗？**
A：不会。除非你自己在设置里开启了云备份，否则应用不会主动上传任何内容。

**Q：必须有 API Key 才能用吗？**
A：不是。不配置 AI 的话，录入、随机、待办、备忘录、搜索、转盘等全部功能都照常可用。

**Q：换手机怎么迁移？**
A：用「数据导出」导出备份文件，或者配置云备份后在新机上恢复。

**Q：为什么有些功能看起来像 Obsidian？**
A：因为作者自己用 Obsidian，觉得它的「源码与渲染共存」手感最好，就照着做了。
